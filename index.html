About Uno

Where it started

Small apps, built for everyday use.

Evox began in 2019. Most of the early apps were written in plain HTML, CSS and JavaScript, with no frameworks. That worked, but the apps now need to be faster and easier to grow, so Uno rebuilds them on a better foundation.

Vision

Fast, reliable, effortless.

Software shouldn’t be limited by browsers, devices or complicated setups. Uno aims for apps that are lightweight and performant, and designed around the person using them first.

Questions

What is Evox Uno?

Uno is a rebuild of Evox. The early apps were written in plain HTML, CSS and JavaScript, and Uno moves them onto a faster foundation that can run outside the browser too.

Can I use it yet?

Not yet. Uno is still in development, and the progress bar at the top shows how far along it is.

Which devices will it run on?

Uno is being built to run beyond the browser, on iOS and Android as well as the web.

Do I need an account?

Yes. You sign in with an Evox account. Once you’re logged in, Settings lets you change your profile photo, name and password, and choose which notifications you get.

Which apps will be in Uno?

The list is in the Apps tile above. It’s loaded from the Uno server, so it shows the current apps when you’re signed in.

How do I get help or send feedback?

Use Support and we’ll get back to you.
